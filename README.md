# AI-Powered News Classification System

## Project Overview

This project develops a supervised machine learning pipeline
for automatically classifying news headlines into predefined
categories using Natural Language Processing (NLP).

## Objectives

- Clean and preprocess news text.
- Convert text into numerical features using TF-IDF.
- Train supervised machine learning classification models.
- Compare model performance using evaluation metrics.
- Deploy the selected model using Streamlit Community Cloud.

## Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Logistic Regression
- Linear Support Vector Machine
- Streamlit

## Machine Learning Workflow

1. Dataset collection
2. Data cleaning
3. Exploratory data analysis
4. Text vectorization
5. Model training
6. Model evaluation
7. Web application development
8. Cloud deployment

## Project Deliverables

- Jupyter Notebook
- Trained classification model
- Streamlit web application
- Project report

## Dataset

The dataset used in the current experiment contains news headlines
and their associated category labels.

The final submission must use the dataset specified in the assignment:
English News Bulletin – August 2025 (Akashvani), available through AIKosh.

## Deployment

The application will be deployed using Streamlit Community Cloud.
